# Support

Use [GitHub issues](https://github.com/manovaspace/lighthouse/issues) for public
Lighthouse questions, reproducible bugs and proposed improvements. Include your
version or commit, relevant tool versions, reproduction steps, and expected and
actual behavior. Check existing issues before opening a new one.

Use synthetic courses, users and grades. Omit student records, credentials,
session tokens, database dumps, private URLs and staff deployment details.
Repository support does not grant access to a course, production system or
private Manova integration. Account, enrollment and grading questions belong with
your course staff through the course's existing channels.

Support is provided as maintainer capacity permits, without a response SLA.
Security reports use the private process in [SECURITY.md](./SECURITY.md).
Contribution instructions are in [CONTRIBUTING.md](./CONTRIBUTING.md).
